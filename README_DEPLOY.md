# Deploying this paper

1. Put index.md at your repo root (or /docs) alongside work/ and submission/.
2. Repo Settings -> Pages -> Source -> pick that branch/folder.
3. Wait ~1-2 min, copy the live URL GitHub shows you.
4. Paste that exact URL as the single line in submission/paper_url.txt (repo root).
5. Commit everything: index.md, work/notebooks/*.ipynb, submission/paper_url.txt.
6. Sanity check: open the Pages URL in an incognito tab before submitting.
